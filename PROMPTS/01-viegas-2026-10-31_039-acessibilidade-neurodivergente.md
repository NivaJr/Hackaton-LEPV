# Prompt 039 — Acessibilidade neurodivergente na interface do aluno

- Data: 2026-10-31
- Autoria: Viegas

## Texto original

Agora precisamos fazer alterações na interface do aluno. Quero integrar a interface para alunos com deficiências como TEA, dislexia e TDAH. Quero que tenha opções de acessibilidade no cadastro do aluno de modo que a plataforma se adapte as condições individuais de cada um.

Utilize artigos referência no assunto de modo a tornar a experiência do usuário conforme os padrões já consolidados de inclusão. Eu li esse artigo por exemplo: [https://brasil.uxdesign.cc/acessibilidade-na-experi%C3%AAncia-do-usu%C3%A1rio-neurodivergente-98f6c34b6da5](https://brasil.uxdesign.cc/acessibilidade-na-experi%C3%AAncia-do-usu%C3%A1rio-neurodivergente-98f6c34b6da5)

Observação: a interface do aluno sem deficiência permanece como está. Muda-se apenas SOMENTE SE o aluno tiver alguma condição de acessibilidade, tendo uma opção para a interface normal caso assim o aluno com deficiência desejar também, sendo o default dele a plataforma acessível.
